## Цель работы

Научиться выявлять переполнение блочных устройств, разделять проблемы нехватки дискового пространства и исчерпания inode, а также устранять утечки памяти на диске, вызванные неудаленными дескрипторами открытых файлов.

## Топология сети

```text
[Workstation: Mac] <===== SSH =====> [Ubuntu Server: Root Partition /]
```

## Чеклист выполнения

1. Подключитесь к серверу по SSH и проверьте утилизацию файловых систем:

   ```bash
   df -h
   df -i
   ```

2. Определите, заняты ли байты на диске или закончились свободные индексы inode.
3. Локализуйте самые «тяжелые» директории:

   ```bash
   sudo du -xh / --max-depth=1 | sort -hr
   ```

4. Если файлы были удалены командой `rm`, но место не освободилось, найдите процессы, удерживающие открытые дескрипторы:

   ```bash
   sudo lsof +L1
   ```

5. Перезапустите соответствующую службу или освободите дескриптор.
6. Настройте ротацию журналов в `/etc/logrotate.d/` для предотвращения повторного переполнения.
