## Что

Продвинутый поиск (Google Dorking / Search Engine Operators) и анализ исторических слепков сайтов (Internet Archive Wayback Machine, archive.today) позволяют обнаруживать случайно проиндексированные конфиденциальные файлы, забытые административные панели и удаленную информацию.

## Зачем

Разработчики и администраторы нередко оставляют в открытом доступе дампы баз данных (`.sql`), файлы конфигурации (`.env`), ключи SSH или резервные архивы (`.tar.gz`), считая, что без прямой ссылки их никто не найдет. Поисковые краулеры автоматически находят и индексируют эти ресурсы.

## Как это работает

Основные техники:

- **Расширенные операторы поисковых систем**:
  - `site:example.com`: ограничение поиска конкретным доменом и его поддоменами.
  - `filetype:pdf` / `filetype:env` / `filetype:log`: поиск по типам файлов.
  - `intitle:"index of"`: поиск открытых листингов директорий веб-серверов.
  - `inurl:admin` / `inurl:login`: обнаружение точек входа в служебные интерфейсы.
- **Анализ истории веб-страниц**: сравнение версий через Wayback Machine API (`web.archive.org`) выявляет удаленные страницы «О компании», прошлые контакты сотрудников или удаленные уязвимые эндпоинты.
- **Поисковые машины исходного кода**: поиск утекших токенов и паролей в публичных репозиториях GitHub / GitLab через фильтры `filename:` и `org:`.
