## Что

PowerShell — современная кроссплатформенная командная оболочка и язык сценариев от Microsoft, спроектированный специально для системного администрирования, управления конфигурациями и автоматизации задач. В отличие от традиционных оболочек Unix (Bash, Zsh) или командной строки Windows (cmd.exe), оперирующих потоками неструктурированного текста, PowerShell построен на базе объектно-ориентированной среды среды выполнения .NET: по конвейеру (Pipeline) передаются полноценные типизированные объекты, обладающие свойствами (Properties) и методами (Methods).

Базовой функциональной единицей PowerShell является командлет (`Cmdlet`, произносится «команд-лет») — компактная команда с предсказуемым синтаксисом именования по схеме «Глагол-Существительное» (`Verb-Noun`), например `Get-Service`, `Start-Process`, `Set-ItemProperty`.

## Зачем

Эпоха ручного администрирования серверов через графические мастера (GUI) ушла в прошлое. В корпоративной инфраструктуре администратор управляет сотнями и тысячами серверов (включая серверы без графической оболочки Windows Server Core), где автоматизация через PowerShell является обязательным профессиональным требованием.

Преимущества объектного конвейера:

- Отсутствие необходимости в парсинге текста через утилиты вроде `grep`, `awk` или `sed`: чтобы узнать объем свободной оперативной памяти или отфильтровать процессы, достаточно обратиться к свойству объекта (`$process.WorkingSet`);
- Интеграция с WMI/CIM, реестром, службами, файловыми системами и Active Directory через унифицированные интерфейсы (PSProviders);
- Мощный механизм удаленного управления PowerShell Remoting (WinRM и SSH).

## Как это работает

1. **Объектный конвейер (Object Pipeline)**:
   При выполнении команды `Get-Process` возвращается массив объектов типа `System.Diagnostics.Process`. Передавая их дальше по конвейеру через символ `|`, мы можем фильтровать и сортировать данные:

   ```powershell
   # Найти процессы, потребляющие более 200 МБ памяти, отсортировать и выбрать топ-5
   Get-Process | Where-Object { $_.WorkingSet -gt 200MB } | Sort-Object WorkingSet -Descending | Select-Object -First 5 Name, CPU, WorkingSet
   ```

2. **Провайдеры PowerShell (PSProviders и PSDrives)**:
   PowerShell абстрагирует различные хранилища данных под видом файловых дисков (Drives):
   - Файловые диски (`C:`, `D:`);
   - Реестр Windows (`HKLM:`, `HKCU:`);
   - Хранилище сертификатов (`Cert:`);
   - Переменные окружения (`Env:`).
     Для навигации и управления ими используются одни и те же универсальные командлеты: `Get-ChildItem` (ls), `Set-Item`, `New-Item`, `Remove-Item`.

3. **Сценарии и политики выполнения (Execution Policy)**:
   Для предотвращения случайного запуска недоверенных скриптов в Windows действует политика `ExecutionPolicy` (`Restricted`, `RemoteSigned`, `AllSigned`, `Unrestricted`). Проверить и настроить текущую политику можно командлетами `Get-ExecutionPolicy` и `Set-ExecutionPolicy`.
