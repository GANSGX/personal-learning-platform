## Что

Windows Event Log — стандартизированная высокопроизводительная служба операционной системы Windows для структурированной записи, хранения и извлечения системных журналов, событий безопасности и телеметрии приложений. В отличие от текстовых файлов журналов в Linux (`/var/log`), события Windows сериализуются в структурированный бинарный XML-формат (`.evtx`), расположенный в каталоге `C:\Windows\System32\winevt\Logs`.

System Monitor (`Sysmon`) — системная служба и драйвер режима ядра из пакета Microsoft Sysinternals, который расширяет стандартные возможности логирования Windows до уровня профессионального мониторинга кибербезопасности (EDR/SIEM), фиксируя создание процессов, сетевые соединения, загрузку драйверов и манипуляции с памятью.

## Зачем

Логирование — основа наблюдаемости (Observability) и информационной безопасности (Cybersecurity). Администраторы серверов и аналитики центров мониторинга безопасности (SOC / Security Operations Center) анализируют журналы Windows для:

- Расследования причин аварийных перезагрузок серверов и сбоев системных служб;
- Обнаружения атак методом подбора паролей (Brute-Force), компрометации учетных записей и аномальной активности в нерабочее время;
- Детектирования вредоносной активности злоумышленников (запуск подозрительных процессов PowerShell, выгрузка паролей из процесса `lsass.exe` через Mimikatz, внедрение кода в чужие процессы);
- Отправки структурированной телеметрии в централизованные системы сбора логов (Elasticsearch / ELK, Splunk, Graylog, Wazuh SIEM).

## Как это работает

1. **Основные каналы Windows Event Log**:
   - `System`: события аппаратного обеспечения, драйверов, обновления системы и Service Control Manager;
   - `Application`: события прикладного программного обеспечения, баз данных и сторонних утилит;
   - `Security`: события входа в систему, изменения прав доступа, блокировки учетных записей (доступен только администраторам);
   - `Microsoft-Windows-Sysmon/Operational`: расширенный канал телеметрии безопасности Sysmon.

2. **Ключевые идентификаторы событий безопасности (Event ID)**:
   - `4624`: Успешный вход в систему (Logon Type 2 — интерактивный, Type 3 — сетевой, Type 10 — RDP);
   - `4625`: Неудачная попытка аутентификации (неверный логин или пароль);
   - `4672`: Вход пользователя с особыми привилегиями (Administrator Logon);
   - `4688`: Создание нового процесса (Process Creation с аргументами командной строки при включенном аудите);
   - `4720` / `4726`: Создание / удаление учетной записи пользователя;
   - `4740`: Блокировка учетной записи из-за превышения числа неверных попыток ввода пароля.

3. **События Sysmon для аналитиков безопасности**:
   - `Event ID 1`: Создание процесса (полная командная строка, хеши исполняемого файла SHA256/MD5, родительский процесс ParentProcessId);
   - `Event ID 3`: Сетевое соединение (IP-адрес назначения, порт, имя процесса, инициировавшего трафик);
   - `Event ID 8`: Создание удаленного потока (CreateRemoteThread — классический маркер Process Injection);
   - `Event ID 10`: Открытие дескриптора процесса (ProcessAccess — перехват обращений к памяти `lsass.exe`).

4. **Работа с журналами через PowerShell**:

   ```powershell
   # Найти последние 10 неудачных попыток входа (Event ID 4625)
   Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4625} -MaxEvents 10 | Format-Table TimeCreated, Message
   ```
