## Что

Сетевой экран хоста (Host Firewall) — подсистема фильтрации входящего, исходящего и транзитного сетевого трафика на основе правил портов, IP-адресов и состояний соединений (Stateful Inspection).

## Зачем

Даже если на сервере случайно запущен тестовый сервис на внутреннем порту (например, база данных без пароля на 0.0.0.0:5432), правильно настроенный брандмауэр блокирует несанкционированный внешний доступ, реализуя принцип минимальных привилегий (Default Deny).

## Как это работает

В ядре Linux фильтрацию пакетов выполняет подсистема `nftables` (или `iptables`). В Ubuntu над ней используется удобная надстройка UFW (Uncomplicated Firewall). Политика по умолчанию блокирует все входящие пакеты (`ufw default deny incoming`) и разрешает исходящие. Администратор явно открывает необходимые служебные порты (`ufw allow 22/tcp`, `ufw allow 80,443/tcp`) и применяет правила через `ufw enable`.

## Контрольная точка

Сформулируйте последовательность команд UFW для настройки базового веб-сервера (SSH на 22 порту, HTTP/HTTPS) с политикой запрета всех остальных входящих подключений.
