## Что

Инструментарий обработки текстовых потоков UNIX — фундаментальный набор утилит командной строки для поиска по регулярным выражениям (`grep`/`ripgrep`), потокового редактирования (`sed`), табличной фильтрации (`awk`) и парсинга структурированного JSON (`jq`).

## Зачем

Инфраструктурные артефакты — логи серверов, дампы баз данных, конфигурационные файлы и ответы REST API — представляют собой структурированный или неструктурированный текст. Мастерство владения этими инструментами позволяет за считанные секунды извлекать метрики, менять конфигурации сотен хостов и агрегировать статистику без написания громоздких программ.

## Как это работает

`grep -E` фильтрует строки по расширенным регулярным выражениям. Потоковый редактор `sed 's/search/replace/g'` производит контекстную замену в потоке. Утилита `awk` оперирует концепцией записей и полей (по умолчанию разделенных пробелами), выполняя арифметику и агрегацию (`awk '{sum += \$1} END {print sum}'`). Процессор `jq` парсит и фильтрует деревья JSON (`curl ... | jq -r '.items[] | select(.status == "ready") | .id'`), обеспечивая надежную работу с API облачных провайдеров.

## Контрольная точка

Напишите конвейер, который парсит вывод команды `docker ps --format "{{json .}}"` с помощью утилиты `jq`, отбирает только контейнеры с именем образа `postgres` и выводит их ID и статус.
