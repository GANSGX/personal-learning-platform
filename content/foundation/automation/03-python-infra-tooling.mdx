## Что

Использование языка Python в инфраструктуре фокусируется не на веб-разработке или Machine Learning, а на написании надежных инструментов автоматизации (CLI), работе с файловой системой, межсетевом взаимодействии по HTTP API и оркестрации процессов ОС.

## Зачем

Когда Bash-скрипт разрастается до сотен строк со сложной логикой, ветвлениями, обработкой ошибок и необходимостью работать со сложными JSON/YAML структурами данных, он становится хрупким и трудноподдерживаемым. Python предоставляет богатую стандартную библиотеку, типизацию и предсказуемую обработку исключений.

## Как это работает

Инфраструктурный код на Python опирается на модули стандартной библиотеки: `pathlib` и `os` (безопасная работа с путями и файлами), `subprocess` (запуск внешних системных утилит через `subprocess.run([...], check=True, capture_output=True)`), `json` и `urllib`/`requests` (работа с сетевыми API) и `argparse` (создание удобных CLI-интерфейсов). Ключевое требование к скриптам автоматизации — идемпотентность (повторный запуск приводит к тому же результату без дублирования или ошибок).
