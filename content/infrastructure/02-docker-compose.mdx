## Что

Docker Compose — декларативный инструмент оркестрации на одном хосте, позволяющий описывать и запускать многокомпонентные стеки (веб-приложение, кэш, база данных, брокер очередей) через единый файл конфигурации `compose.yaml`.

## Зачем

Запуск нескольких взаимосвязанных контейнеров вручную через `docker run` требует передачи десятков флагов сетей, томов, переменных окружения и проброса портов. Compose автоматизирует создание изолированной сети, подключение хранилищ и порядок запуска сервисов одной командой.

## Как это работает

В манифесте Compose описываются секции:

- `services`: контейнеры стека (параметры `image`/`build`, `environment`, `ports`, `depends_on`).
- `networks`: пользовательские мостовые сети (bridge network), обеспечивающие встроенный Service Discovery по именам сервисов через внутренний DNS-резолвер Docker.
- `volumes`: персистентные тома для сохранения данных баз данных при перезапуске контейнеров.
  Команда `docker compose up -d` парсит YAML, создает сеть, монтирует тома и запускает сервисы с учетом зависимостей (`healthcheck`).
