## Что

Инфраструктура как код (Infrastructure as Code, IaC) — подход к управлению вычислительными ресурсами (виртуальными машинами, сетями, хранилищами, DNS-записями) через декларативные текстовые файлы конфигурации с версионированием в Git. Terraform / OpenTofu — отраслевой стандарт декларативного IaC для мультиоблачных сред.

## Зачем

Создание облачных ресурсов вручную через веб-консоль (ClickOps) непрозрачно, не оставляет истории изменений, подвержено человеческим ошибкам и невозможно для быстрого воспроизведения при авариях или развертывании тестовых стендов.

## Как это работает

Terraform использует язык HCL (HashiCorp Configuration Language) и модель управления состоянием (State):

1. **Providers**: плагины для взаимодействия с API провайдеров (AWS, GCP, Yandex Cloud, Cloudflare, Kubernetes).
2. **State (`terraform.tfstate`)**: снимок соответствия объявленных ресурсов реальным объектам в облаке, хранящийся в удаленном хранилище (S3/Object Storage) с блокировкой от одновременных изменений (State Locking).
3. **Workflow**:
   - `terraform init`: инициализация бэкенда и загрузка провайдеров.
   - `terraform plan`: расчет графа зависимостей (`Directed Acyclic Graph`, DAG) и вывод планируемых изменений (создание, изменение, удаление).
   - `terraform apply`: выполнение вызовов API для приведения инфраструктуры к целевому состоянию.
