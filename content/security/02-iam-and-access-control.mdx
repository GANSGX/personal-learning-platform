## Что

Управление идентификацией и доступом (Identity and Access Management, IAM) — комплекс политик и технологий, гарантирующих, что нужные пользователи и сервисы получают санкционированный доступ к ресурсам в соответствии с их контекстом и ролями.

## Зачем

Смешение понятий «кто ты» (аутентификация) и «что тебе разрешено делать» (авторизация) — одна из главных причин уязвимостей в корпоративных сетях и API (Broken Object Level Authorization, IDOR). Четкие модели доступа и принцип наименьших привилегий (Principle of Least Privilege) минимизируют ущерб при компрометации отдельной учетной записи.

## Как это работает

IAM включает этапы:

1. **Идентификация (Identification)**: предъявление идентификатора (логин, email, API key ID).
2. **Аутентификация (Authentication, AuthN)**: подтверждение подлинности субъекта:
   - Знание (пароль, PIN)
   - Владение (TOTP-токен, аппаратный FIDO2/U2F ключ)
   - Биометрия (отпечаток, FaceID). Многофакторная аутентификация (MFA) требует комбинации минимум двух разных категорий.
3. **Авторизация (Authorization, AuthZ)**: проверка прав на выполнение запрошенной операции:
   - **RBAC (Role-Based Access Control)**: права привязаны к ролям (Admin, Editor, Viewer).
   - **ABAC (Attribute-Based Access Control)**: политики оценивают атрибуты субъекта, объекта, действия и контекста (время суток, IP-адрес, уровень риска).
4. **Учет (Accounting / Auditing)**: логирование всех попыток доступа для аудита безопасности.
