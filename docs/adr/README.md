# Architecture Decision Records

Короткие записи «почему так, а не иначе».

Формат имени: `0001-short-title.md`

- [0003](./0003-ru-default-i18n.md) — русский по умолчанию, английский вторым языком

Пишем ADR, когда меняется граница пакетов, стек, схема графа, хранение контента или progress. Не пишем на каждый UI-твик.
